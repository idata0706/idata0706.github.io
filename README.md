Make Repo Public:
Github Pages only works with public repos.

Go to Repo - Settings
Scroll to Danger Zone
Change repo visibility
Toggle from Private to Public


Enable Pages:
In the repo go to Settings - Pages
Under Source 
Branch = main 
Folder = /(root)
Save


Open browser:
Goto https://idata0706.github.io
wait a few minutes for github to deploy
